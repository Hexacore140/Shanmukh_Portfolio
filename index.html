Technical Report · Introduction to AI & ML · Semester I
Automatic Number Plate Detection System

Abstract

Design, implementation, and evaluation of an ANPD system using computer vision and deep learning. The system leverages OpenCV for image preprocessing, YOLOv5 for plate localisation, and EasyOCR for character recognition. Testing on a dataset of 500+ Indian vehicle images yielded a detection accuracy of 92.3%, demonstrating the system's practical viability for traffic management applications.

System Architecture

Stage 1 — Image Preprocessing: Input frames are converted to grayscale, subjected to bilateral filtering to reduce noise while preserving edges, and Canny edge detection is applied to identify regions of interest.

Stage 2 — Plate Localisation: A fine-tuned YOLOv5 model trained on a custom dataset of Indian number plates identifies and extracts bounding box coordinates of the plate region with high precision.

Stage 3 — Character Recognition: The cropped plate region is passed to EasyOCR, which performs multi-language OCR optimised for alphanumeric plate characters, outputting the plate text string.

Results & Analysis

The system was evaluated on 500 test images across varying conditions (daytime, nighttime, rain, motion blur):

Detection Accuracy92.3%All conditions
Precision94.1%Good lighting

Conclusion

This project successfully demonstrates the practical implementation of a real-time ANPD system using modern deep learning tools. The combination of YOLOv5 and EasyOCR proved effective for Indian plate recognition. Future work will focus on improving low-light performance and integrating the system with a live traffic camera feed for real-world deployment testing.
